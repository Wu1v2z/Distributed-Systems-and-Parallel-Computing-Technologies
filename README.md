# Технології розподілених систем та паралельних обчислень

Репозиторій містить лабораторні роботи з дисципліни. Кожна робота має окремий проєкт із програмним кодом та поясненням для захисту.

## Лабораторна робота №1

Програма додає числа обмеженого масиву у трьох окремих потоках. Масив поділено на три нерівні частини (20 %, 30 % і 50 %), а потоки створюються рекурсивно. Для кожної частини та всієї програми вимірюється час виконання.

Файли роботи:

- `lab1/Program.cs` — програмний код;
- `lab1/Lab1.csproj` — конфігурація .NET-проєкту;
- `docs/Lab1_пояснення.md` — звіт і матеріал для захисту;
- `.vscode/` — готові налаштування запуску у VS Code.

## Запуск

Потрібен .NET SDK 8 або новіший.

У терміналі з кореня репозиторію:

```powershell
dotnet run --project .\lab1\Lab1.csproj
```

У VS Code відкрийте панель **Run and Debug**, виберіть конфігурацію **«ЛР1 — багатопотокова сума»** і натисніть `F5`.
